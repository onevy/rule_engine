# 规则引擎字段元数据清单 V1.0

## 一、文档说明

本文档定义了规则引擎支持的所有字段元数据，包括字段编码、字段名称、数据类型、值域范围、支持的操作符等。这些字段将在规则配置界面的Query Builder组件中使用。

## 三、操作符定义

### 3.1 比较操作符（用于数值、日期）

| 操作符编码 | 操作符名称 | 适用类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| eq | 等于(=) | Number, String, Date, Boolean | 精确匹配 | 年龄 = 18 |
| neq | 不等于(≠) | Number, String, Date | 不等于 | 性别 ≠ 男 |
| gt | 大于(>) | Number, Date | 严格大于 | 年龄 > 18 |
| gte | 大于等于(≥) | Number, Date | 大于或等于 | 年龄 ≥ 18 |
| lt | 小于(<) | Number, Date | 严格小于 | 年龄 < 60 |
| lte | 小于等于(≤) | Number, Date | 小于或等于 | 年龄 ≤ 60 |
| between | 在范围内 | Number, Date | 闭区间[a, b] | 年龄 between 18 and 60 |

### 3.2 集合操作符（用于数组、多选）

| 操作符编码 | 操作符名称 | 适用类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| in | 包含(in) | String, Array | 值在列表中 | 诊断编码 in [B22.100, B22.200] |
| not_in | 不包含(not in) | String, Array | 值不在列表中 | 诊断编码 not in [A00.001] |
| contains | 包含 | String, Array | 字符串包含或数组包含元素 | 检查所见 contains "双肺散在性病灶" |
| not_contains | 不包含 | String, Array | 字符串不包含或数组不包含元素 | 检查所见 not contains "正常" |

### 3.3 字符串操作符

| 操作符编码 | 操作符名称 | 适用类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| left_match | 左匹配 | String | 以指定字符串开头 | 诊断编码 left_match "B20" |
| fuzzy_match | 模糊匹配 | String | 正则表达式匹配 | 诊断名称 fuzzy_match ".*肺炎.*" |
| starts_with | 以...开始 | String | 同left_match | - |
| ends_with | 以...结束 | String | 以指定字符串结尾 | - |

### 3.4 空值操作符

| 操作符编码 | 操作符名称 | 适用类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| is_null | 为空 | All | 字段值为null | 手术编码 is null |
| is_not_null | 不为空 | All | 字段值不为null | 手术编码 is not null |

### 3.5 布尔操作符

| 操作符编码 | 操作符名称 | 适用类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| eq | 等于 | Boolean | true或false | 是否妊娠 = true |

## 五、数据格式规范

### 5.1 日期格式
- 标准格式：`yyyy-MM-dd`（如：2025-01-08）
- 日期时间格式：`yyyy-MM-dd HH:mm:ss`（如：2025-01-08 14:30:00）

### 5.2 数值格式
- 整数：不带小数点（如：25）
- 小数：最多保留4位小数（如：24.75）
- 百分比：以小数形式存储（如：0.3表示30%）

### 5.3 布尔值
- true：真、是、1
- false：假、否、0

### 5.4 数组格式
- JSON数组：`["item1", "item2", "item3"]`
- 逗号分隔字符串：`item1,item2,item3`

### 5.5 编码规范
- ICD-10诊断编码：如 B22.100（艾滋病）
- ICD-9-CM-3手术编码：如 54.11（剖腹探查）
- 药品编码：遵循国家药品编码规范

## 六、字段扩展机制

### 6.1 自定义字段
系统支持为每个场景（scene）定义自定义字段，通过`rule_metadata`表配置：

```sql
INSERT INTO rule_metadata (
    scene_id,
    field_code,
    field_name,
    field_type,
    field_source,
    value_range,
    compute_expression,
    description,
    sort_order
) VALUES (
    1,
    'custom_indicator',
    '自定义指标',
    'NUMBER',
    'COMPUTE',
    NULL,
    'patient_age * 1.5',
    '根据年龄计算的自定义指标',
    100
);
```

### 6.2 计算字段
支持基于其他字段计算的派生字段：
- **BMI**: `patient_weight / (patient_height / 100)^2`
- **住院天数**: `discharge_date - admission_date`
- **药占比**: `drug_cost / total_cost * 100`

### 6.3 字段分组
字段可按业务分组管理：
- 基本信息组
- 诊断信息组
- 检验信息组
- 检查信息组
- 手术信息组
- 费用信息组
- 质控指标组

### 7.3 字段命名规范
- 使用小写字母和下划线
- 前缀表示分类：
  - `diagnosis_`: 诊断相关
  - `lab_`: 检验相关
  - `exam_`: 检查相关
  - `operation_`: 手术相关
  - `patient_`: 患者相关
  - `pathology_`: 病理相关
  - `drug_`: 药品相关
