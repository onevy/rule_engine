# 规则引擎用户操作手册

## 1. 系统概述

规则引擎是一个通用的业务规则管理平台，支持传染病报卡、处方审核、病历质控等多个医疗业务场景。通过可视化界面配置规则，实现业务规则的灵活管理和高效执行。

## 2. 快速开始

### 2.1 登录系统

1. 访问系统地址: `http://localhost` (或实际部署地址)
2. 使用用户名和密码登录

### 2.2 系统导航

左侧菜单包含以下模块：
- **规则管理**: 规则列表、创建、编辑、删除
- **场景管理**: 业务场景配置
- **规则组管理**: 规则分组管理
- **元数据管理**: 字段定义配置
- **执行日志**: 规则执行记录查询
- **版本管理**: 规则版本历史

## 3. 规则管理

### 3.1 查看规则列表

1. 点击左侧菜单 "规则管理"
2. 可通过场景、规则名称、编码、状态进行筛选
3. 列表显示规则基本信息和操作按钮

### 3.2 创建规则

1. 点击 "新增规则" 按钮
2. 填写基本信息：
   - **规则编码**: 唯一标识，如 `ID_HIV_REPORT`
   - **规则名称**: 规则中文名称
   - **所属场景**: 选择业务场景
   - **所属规则组**: 选择规则分组
   - **优先级**: 数值越大优先级越高
   - **生效时间**: 规则生效的时间范围

3. 配置规则条件：
   - 点击 "添加条件" 添加新条件
   - 选择字段、操作符、填写值
   - 使用条件组实现复杂的 AND/OR 逻辑
   - 同一组内的条件默认使用 AND 连接
   - 不同组之间使用 OR 连接

4. 配置规则动作：
   - 点击 "添加动作" 添加执行动作
   - 选择动作类型：
     - `RETURN`: 返回数据
     - `CALL_SERVICE`: 调用服务
     - `SEND_MESSAGE`: 发送消息
   - 配置动作参数（JSON格式）

5. 点击 "保存" 完成创建

### 3.3 编辑规则

1. 在规则列表中点击 "编辑" 按钮
2. 修改规则信息、条件或动作
3. 点击 "保存" 提交修改

### 3.4 复制规则

1. 在规则列表中点击 "复制" 按钮
2. 系统自动创建规则副本
3. 副本规则默认为禁用状态

### 3.5 启用/禁用规则

- 点击规则列表中的开关切换状态
- 或使用批量操作：勾选多条规则后选择 "批量启用" 或 "批量禁用"

### 3.6 删除规则

1. 点击 "删除" 按钮
2. 确认删除操作
3. 批量删除：勾选多条规则后点击 "批量删除"

## 4. 规则导入导出

### 4.1 导出规则

1. 方式一：点击 "导出" 按钮导出当前场景所有规则
2. 方式二：勾选需要导出的规则，点击 "导出选中"
3. 系统下载 JSON 格式的规则文件

### 4.2 导入规则

1. 点击 "导入" 按钮
2. 选择规则 JSON 文件
3. 选择冲突处理策略：
   - **跳过**: 规则编码已存在时跳过
   - **覆盖**: 规则编码已存在时覆盖原规则
   - **重命名**: 自动重命名后导入
4. 选择是否导入后自动启用
5. 点击 "确认导入"
6. 查看导入结果详情

## 5. 条件配置说明

### 5.1 支持的操作符

| 操作符 | 说明 | 适用类型 | 示例 |
|--------|------|----------|------|
| EQ | 等于 | 所有类型 | `status = 1` |
| NEQ | 不等于 | 所有类型 | `status != 0` |
| GT | 大于 | 数字、日期 | `age > 18` |
| GTE | 大于等于 | 数字、日期 | `age >= 18` |
| LT | 小于 | 数字、日期 | `age < 60` |
| LTE | 小于等于 | 数字、日期 | `age <= 60` |
| IN | 包含于 | 字符串、数组 | `code IN ['A', 'B']` |
| NOT_IN | 不包含于 | 字符串、数组 | `code NOT IN ['C']` |
| LIKE | 模糊匹配 | 字符串 | `name LIKE '肺炎'` |
| LEFT_MATCH | 左匹配 | 字符串 | `code starts with 'B20'` |
| BETWEEN | 区间 | 数字、日期 | `age BETWEEN 18 AND 60` |
| IS_NULL | 为空 | 所有类型 | `field IS NULL` |
| IS_NOT_NULL | 不为空 | 所有类型 | `field IS NOT NULL` |

### 5.2 条件组逻辑

- **同一条件组内**：条件之间使用 AND 连接
- **不同条件组之间**：使用 OR 连接

示例：
```
(诊断编码 IN ['B20', 'B21']) OR (HIV抗体 = '阳性')
```

## 6. 规则执行

### 6.1 测试规则

1. 在规则详情页点击 "测试" 按钮
2. 输入测试数据（JSON格式）
3. 点击 "执行测试"
4. 查看测试结果和匹配的规则

### 6.2 查看执行日志

1. 点击左侧菜单 "执行日志"
2. 按条件筛选日志记录
3. 点击日志详情查看：
   - 输入数据
   - 输出结果
   - 命中的规则
   - 执行耗时

## 7. 场景管理

### 7.1 查看场景

1. 点击左侧菜单 "场景管理"
2. 查看已配置的业务场景列表

### 7.2 场景元数据

每个场景包含：
- 场景编码和名称
- 适配器类配置
- 字段元数据定义
- 支持的操作符

## 8. 规则组管理

### 8.1 规则组功能

规则组用于组织和管理规则：
- 按业务类型分组（如：甲类传染病、乙类传染病）
- 配置执行模式：ALL（全部执行）/ FIRST（首个匹配）

### 8.2 管理规则组

1. 点击左侧菜单 "规则组管理"
2. 可创建、编辑、删除规则组
3. 支持规则组层级嵌套

## 9. 常见问题

### Q1: 规则保存后没有生效？
A: 请检查：
1. 规则是否已启用
2. 生效时间是否在有效范围内
3. 如使用缓存，可能需要刷新缓存

### Q2: 导入规则失败？
A: 请检查：
1. JSON文件格式是否正确
2. 规则编码是否已存在（选择合适的冲突策略）
3. 场景编码是否有效

### Q3: 规则执行结果不符合预期？
A: 建议：
1. 使用测试功能验证规则
2. 检查条件配置是否正确
3. 查看执行日志分析原因
4. 注意条件组的 AND/OR 逻辑

### Q4: 如何批量操作规则？
A:
1. 在规则列表勾选需要操作的规则
2. 使用批量操作下拉菜单
3. 支持：批量启用、批量禁用、批量导出、批量删除
