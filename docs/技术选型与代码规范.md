#### 2.3.2 Controller层

```java
@RestController
@RequestMapping("/api/v1/rules")
@Slf4j
@Tag(name = "规则管理", description = "规则CRUD接口")
public class RuleController {

    @Autowired
    private RuleService ruleService;

    @GetMapping("/{ruleCode}")
    @Operation(summary = "获取规则详情")
    public Result<RuleDetailResponse> getByCode(
            @PathVariable @NotBlank(message = "规则编码不能为空") String ruleCode) {
        log.info("查询规则详情, ruleCode: {}", ruleCode);
        RuleDetailResponse response = ruleService.getByCode(ruleCode);
        return Result.success(response);
    }

    @PostMapping
    @Operation(summary = "创建规则")
    public Result<Long> create(@RequestBody @Valid RuleCreateRequest request) {
        log.info("创建规则, request: {}", request);
        Long ruleId = ruleService.create(request);
        return Result.success(ruleId);
    }
}
```

**规范要点**:
- 使用`@RestController`和`@RequestMapping`定义RESTful接口
- 使用`@Slf4j`注解自动注入日志对象
- 使用Swagger注解生成API文档
- 参数校验使用`@Valid`和`@Validated`
- 统一返回`Result`对象

#### 2.3.3 Service层

```java
@Service
@Slf4j
public class RuleServiceImpl implements RuleService {

    @Autowired
    private RuleMapper ruleMapper;

    @Autowired
    private RuleCompiler ruleCompiler;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long create(RuleCreateRequest request) {
        // 1. 参数校验
        validateRequest(request);

        // 2. 检查规则编码是否已存在
        if (existsByCode(request.getRuleCode())) {
            throw new BusinessException("规则编码已存在");
        }

        // 3. 编译规则
        String drlContent = ruleCompiler.compile(request.getJsonConfig());

        // 4. 构建实体对象
        Rule rule = buildRule(request, drlContent);

        // 5. 保存到数据库
        ruleMapper.insert(rule);

        // 6. 清除缓存
        clearCache(request.getSceneCode());

        log.info("规则创建成功, ruleId: {}, ruleCode: {}", rule.getId(), rule.getRuleCode());
        return rule.getId();
    }

    private void validateRequest(RuleCreateRequest request) {
        // 校验逻辑
    }

    private boolean existsByCode(String ruleCode) {
        return ruleMapper.selectCount(
            new LambdaQueryWrapper<Rule>()
                .eq(Rule::getRuleCode, ruleCode)
                .eq(Rule::getIsDeleted, 0)
        ) > 0;
    }

    private Rule buildRule(RuleCreateRequest request, String drlContent) {
        return Rule.builder()
            .ruleCode(request.getRuleCode())
            .ruleName(request.getRuleName())
            .drlContent(drlContent)
            .build();
    }

    private void clearCache(String sceneCode) {
        String cacheKey = "rule:scene:" + sceneCode;
        redisTemplate.delete(cacheKey);
    }
}
```

**规范要点**:
- 事务方法使用`@Transactional`,指定`rollbackFor = Exception.class`
- 复杂业务逻辑拆分为多个私有方法,提高可读性
- 重要操作添加日志记录
- 使用MyBatis-Plus的LambdaQueryWrapper构建查询
- 使用Lombok的`@Builder`简化对象构建

#### 2.3.5 异常处理

```java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    /**
     * 业务异常
     */
    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.fail(e.getCode(), e.getMessage());
    }

    /**
     * 参数校验异常
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidException(MethodArgumentNotValidException e) {
        List<String> errors = e.getBindingResult()
            .getFieldErrors()
            .stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.toList());
        log.warn("参数校验失败: {}", errors);
        return Result.fail(400, "参数校验失败", errors);
    }

    /**
     * 系统异常
     */
    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.fail(500, "系统内部错误");
    }
}
```

### 2.4 日志规范

#### 2.4.1 日志级别使用

- **ERROR**: 系统错误,需要人工介入
- **WARN**: 警告信息,业务异常
- **INFO**: 重要业务流程,接口调用
- **DEBUG**: 调试信息,仅开发环境使用

#### 2.4.2 日志示例

```java
// 接口入口日志
log.info("创建规则, ruleCode: {}, ruleName: {}", ruleCode, ruleName);

// 业务异常
log.warn("规则编码已存在, ruleCode: {}", ruleCode);

// 系统错误
log.error("规则编译失败, ruleCode: {}", ruleCode, e);

// 调试信息
log.debug("查询条件: {}", queryWrapper);
```

**规范要点**:
- 使用占位符`{}`而非字符串拼接
- 关键业务参数必须记录
- 异常信息记录异常对象

### 3.5 API封装

```typescript
// api/request.ts

import axios, { AxiosInstance, AxiosRequestConfig, AxiosResponse } from 'axios'
import { ElMessage } from 'element-plus'
import { getToken } from '@/utils/auth'

// 创建axios实例
const service: AxiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000
})

// 请求拦截器
service.interceptors.request.use(
  (config) => {
    // 添加token
    const token = getToken()
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => {
    return Promise.reject(error)
  }
)

// 响应拦截器
service.interceptors.response.use(
  (response: AxiosResponse) => {
    const { code, message, data } = response.data

    if (code === 200) {
      return response.data
    } else if (code === 401) {
      ElMessage.error('登录已过期,请重新登录')
      // 跳转到登录页
      window.location.href = '/login'
      return Promise.reject(new Error(message))
    } else {
      ElMessage.error(message || '请求失败')
      return Promise.reject(new Error(message))
    }
  },
  (error) => {
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default service
```

- **发布分支**: `release/版本号`, 如 `release/v1.0.0`
- **紧急修复**: `hotfix/问题描述`, 如 `hotfix/security-fix`
