# 操作符定义与Drools转换规则 V1.0

## 一、文档说明

本文档详细定义了规则引擎支持的所有操作符，包括操作符的语义、适用场景、前端展示、JSON格式以及到Drools DRL的转换规则。

---

## 二、操作符完整清单

### 2.1 比较操作符（Comparison Operators）

#### EQ（等于）

**语义**: 精确相等匹配

**适用类型**: String, Number, Date, Boolean

**前端展示**: `等于 (=)`

**JSON格式**:
```json
{
  "operator": "EQ",
  "leftValue": "patient_age",
  "rightValue": "18",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
// Number类型
$data.get("patient_age") == 18

// String类型
$data.get("diagnosis_name") == "肺炎"

// Boolean类型
$data.get("patient_pregnancy") == true
```

---

#### NEQ（不等于）

**语义**: 不相等

**适用类型**: String, Number, Date

**前端展示**: `不等于 (≠)`

**JSON格式**:
```json
{
  "operator": "NEQ",
  "leftValue": "patient_gender",
  "rightValue": "男",
  "valueType": "STRING"
}
```

**DRL转换规则**:
```java
$data.get("patient_gender") != "男"
```

---

#### GT（大于）

**语义**: 严格大于

**适用类型**: Number, Date

**前端展示**: `大于 (>)`

**JSON格式**:
```json
{
  "operator": "GT",
  "leftValue": "patient_age",
  "rightValue": "18",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
// Number类型
$data.get("patient_age") > 18

// Date类型（需要日期对象）
$data.get("admission_date") > new java.util.Date("2025-01-01")
```

---

#### GTE（大于等于）

**语义**: 大于或等于

**适用类型**: Number, Date

**前端展示**: `大于等于 (≥)`

**JSON格式**:
```json
{
  "operator": "GTE",
  "leftValue": "lab_wbc",
  "rightValue": "24.75",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
$data.get("lab_wbc") >= 24.75
```

---

#### LT（小于）

**语义**: 严格小于

**适用类型**: Number, Date

**前端展示**: `小于 (<)`

**JSON格式**:
```json
{
  "operator": "LT",
  "leftValue": "patient_age",
  "rightValue": "60",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
$data.get("patient_age") < 60
```

---

#### LTE（小于等于）

**语义**: 小于或等于

**适用类型**: Number, Date

**前端展示**: `小于等于 (≤)`

**JSON格式**:
```json
{
  "operator": "LTE",
  "leftValue": "patient_age",
  "rightValue": "60",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
$data.get("patient_age") <= 60
```

---

#### BETWEEN（在范围内）

**语义**: 闭区间范围匹配[a, b]

**适用类型**: Number, Date

**前端展示**: `在...之间`

**JSON格式**:
```json
{
  "operator": "BETWEEN",
  "leftValue": "patient_age",
  "rightValue": "18,60",
  "valueType": "NUMBER"
}
```

**DRL转换规则**:
```java
// Number类型
($data.get("patient_age") >= 18 && $data.get("patient_age") <= 60)

// Date类型
($data.get("admission_date") >= new java.util.Date("2025-01-01") &&
 $data.get("admission_date") <= new java.util.Date("2025-12-31"))
```

---

### 2.2 集合操作符（Set Operators）

#### IN（包含）

**语义**: 值在列表中（枚举匹配）

**适用类型**: String, Number（针对单值匹配多个可能值）

**前端展示**: `包含 (in)`

**JSON格式**:
```json
{
  "operator": "IN",
  "leftValue": "diagnosis_code",
  "rightValue": ["B22.100", "B22.200", "B22.700", "B22.701", "B23.100", "B23.200"],
  "valueType": "ARRAY"
}
```

**DRL转换规则**:
```java
// String数组
$data.get("diagnosis_code") memberOf ["B22.100", "B22.200", "B22.700", "B22.701", "B23.100", "B23.200"]

// 或者使用contains（Drools的List.contains方法）
["B22.100", "B22.200", "B22.700"].contains($data.get("diagnosis_code"))
```

---

#### NOT_IN（不包含）

**语义**: 值不在列表中

**适用类型**: String, Number

**前端展示**: `不包含 (not in)`

**JSON格式**:
```json
{
  "operator": "NOT_IN",
  "leftValue": "diagnosis_code",
  "rightValue": ["A00.001", "A00.002"],
  "valueType": "ARRAY"
}
```

**DRL转换规则**:
```java
$data.get("diagnosis_code") not memberOf ["A00.001", "A00.002"]

// 或者
!["A00.001", "A00.002"].contains($data.get("diagnosis_code"))
```

---

#### CONTAINS（包含元素）

**语义**: 字符串包含子串或数组包含元素

**适用类型**: String, Array

**前端展示**: `包含`

**JSON格式**:
```json
// 字符串包含
{
  "operator": "CONTAINS",
  "leftValue": "exam_ct_findings",
  "rightValue": "双肺散在性病灶",
  "valueType": "STRING"
}

// 数组包含
{
  "operator": "CONTAINS",
  "leftValue": "drug_codes",
  "rightValue": "Drug001",
  "valueType": "STRING"
}
```

**DRL转换规则**:
```java
// 字符串包含（使用contains方法）
$data.get("exam_ct_findings").toString().contains("双肺散在性病灶")

// 数组包含
$data.get("drug_codes") contains "Drug001"
```

---

#### NOT_CONTAINS（不包含元素）

**语义**: 字符串不包含子串或数组不包含元素

**适用类型**: String, Array

**前端展示**: `不包含`

**JSON格式**:
```json
{
  "operator": "NOT_CONTAINS",
  "leftValue": "exam_ct_findings",
  "rightValue": "正常",
  "valueType": "STRING"
}
```

**DRL转换规则**:
```java
// 字符串不包含
!$data.get("exam_ct_findings").toString().contains("正常")

// 数组不包含
$data.get("drug_codes") not contains "Drug001"
```

---

### 2.3 字符串操作符（String Operators）

**语义**: 字符串以指定前缀开头



---


---

**前端展示**: `以...开始`

**DRL转换规则**:

---

#### ENDS_WITH（以...结束）

**语义**: 字符串以指定后缀结束

**前端展示**: `以...结束`


**DRL转换规则**:


## 三、复杂条件组合

### 3.1 AND逻辑（并且）

**语义**: 所有条件都必须满足

**JSON格式**:
```json
{
  "logic": "AND",
  "conditions": [
    {
      "field": "patient_age",
      "operator": "GT",
      "value": "18"
    },
    {
      "field": "patient_gender",
      "operator": "EQ",
      "value": "女"
    },
    {
      "field": "patient_pregnancy",
      "operator": "EQ",
      "value": "true"
    }
  ]
}
```

**DRL转换规则**:
```java
$data : Map(
    this["patient_age"] > 18 &&
    this["patient_gender"] == "女" &&
    this["patient_pregnancy"] == true
)
```

---

### 3.2 OR逻辑（或者）

**语义**: 任一条件满足即可

**JSON格式**:
```json
{
  "logic": "OR",
  "conditions": [
    {
      "field": "diagnosis_code",
      "operator": "IN",
      "value": ["B22.100", "B22.200"]
    },
    {
      "field": "diagnosis_name",
      "operator": "LEFT_MATCH",
      "value": "B20"
    }
  ]
}
```

**DRL转换规则**:
```java
$data : Map(
    this["diagnosis_code"] memberOf ["B22.100", "B22.200"] ||
    this["diagnosis_name"].toString().startsWith("B20")
)
```

---

### 3.3 嵌套条件组（AND/OR混合）

**语义**: 支持多层嵌套的复杂逻辑

**JSON格式**:
```json
{
  "logic": "OR",
  "groups": [
    {
      "logic": "AND",
      "conditions": [
        {
          "field": "diagnosis_code",
          "operator": "IN",
          "value": ["B22.100", "B22.200"]
        },
        {
          "field": "patient_age",
          "operator": "GT",
          "value": "18"
        }
      ]
    },
    {
      "logic": "AND",
      "conditions": [
        {
          "field": "lab_hiv",
          "operator": "EQ",
          "value": "阳性"
        },
        {
          "field": "lab_wbc",
          "operator": "LT",
          "value": "4.0"
        }
      ]
    }
  ]
}
```

**DRL转换规则**:
```java
$data : Map(
    (this["diagnosis_code"] memberOf ["B22.100", "B22.200"] &&
     this["patient_age"] > 18) ||
    (this["lab_hiv"] == "阳性" &&
     this["lab_wbc"] < 4.0)
)
```

**逻辑表达式**（参考原型图rule2.jpg）:
```
(A and B) or (C and D)
= (诊断编码 in [B22.100, B22.200] AND 年龄 > 18) OR (HIV抗体 = 阳性 AND 白细胞 < 4.0)
```

## 四、数据类型转换规则

### 4.1 String类型

**JSON格式**:
```json
{
  "valueType": "STRING",
  "value": "肺炎"
}
```

**DRL转换**:
```java
"肺炎"  // 需要添加双引号
```

**特殊字符处理**:
- 双引号：`"`需要转义为`\"`
- 反斜杠：`\`需要转义为`\\`
- 换行符：`\n`需要转义

---

### 4.2 Number类型

**JSON格式**:
```json
{
  "valueType": "NUMBER",
  "value": "24.75"
}
```

**DRL转换**:
```java
24.75  // 直接输出数值，不带引号
```

**整数和小数处理**:
- 整数：`18` → `18`
- 小数：`24.75` → `24.75`
- 科学计数法：`1.5e10` → `1.5e10`

---

### 4.3 Boolean类型

**JSON格式**:
```json
{
  "valueType": "BOOLEAN",
  "value": "true"
}
```

**DRL转换**:
```java
true  // 小写，不带引号
false // 小写，不带引号
```

---

### 4.4 Date类型

**JSON格式**:
```json
{
  "valueType": "DATE",
  "value": "2025-01-08"
}
```

**DRL转换**:
```java
// 使用java.text.SimpleDateFormat解析
new java.text.SimpleDateFormat("yyyy-MM-dd").parse("2025-01-08")

// 或者使用自定义函数
DateUtil.parse("2025-01-08")
```

---

### 4.5 Array类型

**JSON格式**:
```json
{
  "valueType": "ARRAY",
  "value": ["B22.100", "B22.200", "B22.700"]
}
```

**DRL转换**:
```java
// String数组
["B22.100", "B22.200", "B22.700"]

// Number数组
[1, 2, 3, 4, 5]
```

## 五、完整规则转换示例

### 5.1 传染病报卡规则示例

**业务需求**（参考原型图rule1.jpg）:
艾滋病(HIV)报卡规则：
- 诊断满足规则：诊断编码包含[B22.100, B22.200, B22.700, B22.701, B23.100, B23.200] 或 诊断名称左匹配"B20"
- 满足提示规则：血常规/白细胞计数 大于等于 24.75 并且 常规检验/血红蛋白（定性）包含[阳性、阴性] 并且 尿常规/尿蛋白（文本）包含"*" 并且 CT/检查所见 包含"双肺散在性病灶" 并且 超声/诊断所见 不包含"不明原因肺类"

**JSON配置**:
```json
{
  "ruleCode": "HIV_001",
  "ruleName": "艾滋病(HIV)报卡规则",
  "sceneCode": "INFECTIOUS_DISEASE_REPORT",
  "groupId": 101,
  "ruleType": "CONDITION",
  "priority": 100,
  "isActive": true,
  "diagnosisConditions": {
    "logic": "OR",
    "groups": [
      {
        "logic": "AND",
        "conditions": [
          {
            "field": "diagnosis_code",
            "operator": "IN",
            "value": ["B22.100", "B22.200", "B22.700", "B22.701", "B23.100", "B23.200"],
            "valueType": "ARRAY"
          }
        ]
      },
      {
        "logic": "AND",
        "conditions": [
          {
            "field": "diagnosis_name",
            "operator": "LEFT_MATCH",
            "value": "B20",
            "valueType": "STRING"
          }
        ]
      }
    ]
  },
  "alertConditions": {
    "logic": "AND",
    "conditions": [
      {
        "field": "lab_wbc",
        "operator": "GTE",
        "value": "24.75",
        "valueType": "NUMBER"
      },
      {
        "field": "lab_hb_qualitative",
        "operator": "IN",
        "value": ["阳性", "阴性"],
        "valueType": "ARRAY"
      },
      {
        "field": "lab_urine_protein",
        "operator": "CONTAINS",
        "value": "*",
        "valueType": "STRING"
      },
      {
        "field": "exam_ct_findings",
        "operator": "CONTAINS",
        "value": "双肺散在性病灶",
        "valueType": "STRING"
      },
      {
        "field": "exam_ultrasound_diagnosis",
        "operator": "NOT_CONTAINS",
        "value": "不明原因肺类",
        "valueType": "STRING"
      }
    ]
  },
  "actions": [
    {
      "actionType": "RETURN",
      "params": {
        "need_report": true,
        "disease_code": "HIV",
        "disease_name": "艾滋病",
        "report_type": "艾滋性病报卡"
      }
    }
  ]
}
```

**生成的Drools DRL**:
```drl
package rules.infectious_disease;

import java.util.Map;
import java.util.List;
import com.ruleengine.core.RuleContext;
import com.ruleengine.core.RuleResult;
import com.ruleengine.core.MatchedRule;

global RuleResult ruleResult;
global RuleContext context;

rule "HIV_001"
    salience 100
when
    $data : Map(
        // 诊断满足规则（OR逻辑）
        (this["diagnosis_code"] memberOf ["B22.100", "B22.200", "B22.700", "B22.701", "B23.100", "B23.200"]) ||
        (this["diagnosis_name"].toString().startsWith("B20"))
    )
    // 满足提示规则（AND逻辑）
    eval(
        $data.get("lab_wbc") != null && (Double)$data.get("lab_wbc") >= 24.75 &&
        $data.get("lab_hb_qualitative") != null && ["阳性", "阴性"].contains($data.get("lab_hb_qualitative")) &&
        $data.get("lab_urine_protein") != null && $data.get("lab_urine_protein").toString().contains("*") &&
        $data.get("exam_ct_findings") != null && $data.get("exam_ct_findings").toString().contains("双肺散在性病灶") &&
        $data.get("exam_ultrasound_diagnosis") != null && !$data.get("exam_ultrasound_diagnosis").toString().contains("不明原因肺类")
    )
then
    // 记录匹配的规则
    MatchedRule matched = new MatchedRule();
    matched.setRuleId(1001L);
    matched.setRuleCode("HIV_001");
    matched.setRuleName("艾滋病(HIV)报卡规则");
    ruleResult.getMatchedRules().add(matched);
    ruleResult.setMatched(true);

    // 执行动作：返回结果
    ruleResult.getOutputData().put("need_report", true);
    ruleResult.getOutputData().put("disease_code", "HIV");
    ruleResult.getOutputData().put("disease_name", "艾滋病");
    ruleResult.getOutputData().put("report_type", "艾滋性病报卡");

    System.out.println("规则 HIV_001 触发：需要上报艾滋病传染病报卡");
end
```

## 六、转换实现要点

### 6.1 空值安全处理

在DRL中访问Map的值时，需要进行null检查：

```java
// 不安全的写法（可能NPE）
$data.get("field_name").toString().contains("value")

// 安全的写法
$data.get("field_name") != null && $data.get("field_name").toString().contains("value")
```

### 6.2 类型转换

从Map获取的值是Object类型，需要显式转换：

```java
// Number类型
(Double)$data.get("patient_age") > 18

// 或使用Number超类
((Number)$data.get("patient_age")).doubleValue() > 18
```

### 6.3 使用eval函数

对于复杂条件，可以使用eval：

```java
when
    $data : Map(...)
    eval(
        $data.get("field1") != null &&
        condition1 &&
        condition2
    )
then
    // actions
end
```

### 6.4 特殊字符转义

```java
// 引号转义
"他说:\"你好\""

// 反斜杠转义
"路径: C:\\Users\\file.txt"

// 正则表达式中的特殊字符
".*\\(肺炎\\).*"  // 匹配"(肺炎)"
```

## 七、操作符优先级

| 优先级 | 操作符类型 | 操作符 |
|-------|-----------|-------|
| 1（最高） | 括号 | ( ) |
| 2 | 一元操作符 | !, not |
| 3 | 比较操作符 | >, >=, <, <=, ==, != |
| 4 | 集合操作符 | memberOf, not memberOf, contains, not contains |
| 5 | 字符串操作符 | matches, startsWith, endsWith |
| 6 | 逻辑与 | &&, and |
| 7（最低） | 逻辑或 | \|\|, or |

---

## 八、性能优化建议

### 8.1 优先使用简单操作符
- 优先使用`==`, `>`, `<`等简单比较
- 避免过度使用正则表达式`matches`
- `startsWith`比`matches`性能更好

### 8.2 减少eval使用
- eval会降低规则引擎性能
- 尽量使用标准的Drools约束语法
- 只在必要时使用eval

### 8.3 合理使用索引
- 频繁查询的字段建立索引
- 使用salience控制规则执行顺序
- 避免规则冲突

## 九、附录

### 9.1 Drools常用函数

| 函数 | 说明 | 示例 |
|-----|------|------|
| memberOf | 元素属于集合 | `$value memberOf $list` |
| not memberOf | 元素不属于集合 | `$value not memberOf $list` |
| contains | 集合包含元素 | `$list contains $value` |
| not contains | 集合不包含元素 | `$list not contains $value` |
| matches | 正则匹配 | `$str matches ".*pattern.*"` |
| startsWith | 字符串以...开始 | `$str.startsWith("prefix")` |
| endsWith | 字符串以...结束 | `$str.endsWith("suffix")` |

### 9.2 错误处理

**常见错误**:

1. **类型不匹配**:
```
错误: $data.get("age") > "18"
正确: $data.get("age") > 18
```

2. **空指针异常**:
```
错误: $data.get("name").toString().contains("张")
正确: $data.get("name") != null && $data.get("name").toString().contains("张")
```

3. **语法错误**:
```
错误: $data.get(diagnosis_code) == "B22.100"
正确: $data.get("diagnosis_code") == "B22.100"
```
