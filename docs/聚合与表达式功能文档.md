# 聚合计算与表达式计算功能文档

## 1. 功能概述

规则引擎扩展了两种高级计算能力，支持评估量表等复杂业务场景：

1. **聚合计算** - 支持对多个字段进行 SUM、AVG、MAX、MIN、COUNT 聚合运算
2. **表达式计算** - 支持 SpEL (Spring Expression Language) 自定义表达式，如反向计分

## 2. 数据库扩展

在 `rule_condition` 表中新增三个字段：

```sql
-- 聚合函数类型: SUM, AVG, MAX, MIN, COUNT
ALTER TABLE rule_condition ADD COLUMN aggregate_function VARCHAR(20) DEFAULT NULL;

-- 聚合字段列表，JSON数组格式
ALTER TABLE rule_condition ADD COLUMN aggregate_fields TEXT DEFAULT NULL;

-- 计算表达式，支持 SpEL 语法
ALTER TABLE rule_condition ADD COLUMN expression TEXT DEFAULT NULL;
```

## 3. 聚合计算

### 3.1 支持的聚合函数

| 函数 | 说明 | 示例 |
|------|------|------|
| SUM | 求和 | 计算总分 |
| AVG | 平均值 | 计算平均分 |
| MAX | 最大值 | 获取最高分 |
| MIN | 最小值 | 获取最低分 |
| COUNT | 计数 | 统计非空字段数 |

### 3.2 配置示例

```json
{
  "ruleId": 1,
  "fieldCode": "totalScore",
  "aggregateFunction": "SUM",
  "aggregateFields": "[\"q1\",\"q2\",\"q3\",\"q4\",\"q5\"]",
  "operator": "BETWEEN",
  "fieldValue": "0,3"
}
```

### 3.3 生成的 DRL 规则

```drools
eval(
    (($data.get("q1") != null ? ((Number)$data.get("q1")).doubleValue() : 0) +
     ($data.get("q2") != null ? ((Number)$data.get("q2")).doubleValue() : 0) +
     ($data.get("q3") != null ? ((Number)$data.get("q3")).doubleValue() : 0) +
     ($data.get("q4") != null ? ((Number)$data.get("q4")).doubleValue() : 0) +
     ($data.get("q5") != null ? ((Number)$data.get("q5")).doubleValue() : 0))
    >= 0 &&
    (($data.get("q1") != null ? ((Number)$data.get("q1")).doubleValue() : 0) +
     ... ) <= 3
)
```

## 4. 表达式计算

### 4.1 支持的语法

表达式使用 SpEL 语法，支持：

- **数学运算**: `+`, `-`, `*`, `/`, `%`
- **比较运算**: `==`, `!=`, `<`, `>`, `<=`, `>=`
- **逻辑运算**: `and`, `or`, `not`
- **数据访问**: `#data['fieldName']` 或 `#data.fieldName`

### 4.2 反向计分示例

在体质评估等场景中，部分题目需要反向计分：

```json
{
  "ruleId": 1,
  "fieldCode": "pingheScore",
  "operator": "EXPRESSION",
  "expression": "#data['q1'] + (6 - #data['q2']) + (6 - #data['q4'])",
  "fieldValue": ">=17"
}
```

上述表达式中：
- `#data['q1']` - 正向计分，直接取值
- `(6 - #data['q2'])` - 反向计分，用6减去原值

### 4.3 表达式语法转换

系统自动将 SpEL 语法转换为 Drools DRL 语法：

| SpEL 语法 | DRL 语法 |
|-----------|----------|
| `#data["q1"]` | `$data.get("q1")` |
| `#data['q1']` | `$data.get("q1")` |
| `#data.q1` | `$data.get("q1")` |

### 4.4 fieldValue 格式

对于 EXPRESSION 操作符，`fieldValue` 字段需要包含比较操作符和值：

```
>=17    -- 大于等于17
<=8     -- 小于等于8
>10     -- 大于10
==100   -- 等于100
!=0     -- 不等于0
```

## 5. ExpressionEvaluator 组件

### 5.1 核心方法

```java
// 通用计算
Object evaluate(String expression, Map<String, Object> context);

// 数值计算
double evaluateAsNumber(String expression, Map<String, Object> context);

// 布尔计算
boolean evaluateAsBoolean(String expression, Map<String, Object> context);

// 聚合计算
double evaluateAggregate(String function, List<String> fields, Map<String, Object> context);

// 表达式验证
String validate(String expression);
```

### 5.2 使用示例

```java
ExpressionEvaluator evaluator = new ExpressionEvaluator();

Map<String, Object> context = new HashMap<>();
context.put("q1", 5);
context.put("q2", 4);
context.put("q3", 3);

// 表达式计算
double score = evaluator.evaluateAsNumber(
    "#data['q1'] + (6 - #data['q2'])", context);
// 结果: 5 + (6 - 4) = 7

// 聚合计算
double total = evaluator.evaluateAggregate(
    "SUM", Arrays.asList("q1", "q2", "q3"), context);
// 结果: 5 + 4 + 3 = 12

// 布尔表达式
boolean pass = evaluator.evaluateAsBoolean(
    "#data['q1'] >= 3 and #data['q2'] >= 3", context);
// 结果: true
```

## 6. 业务场景示例

### 6.1 自理能力评估 (总分模式)

```json
{
  "conditions": [{
    "fieldCode": "totalScore",
    "aggregateFunction": "SUM",
    "aggregateFields": "[\"q1\",\"q2\",\"q3\",\"q4\",\"q5\"]",
    "operator": "BETWEEN",
    "fieldValue": "0,3"
  }],
  "actions": [{
    "actionType": "RETURN",
    "actionParams": "{\"result\":\"重度依赖\",\"level\":4}"
  }]
}
```

### 6.2 体质评估 (分组得分模式)

平和质判定规则：
1. 平和质得分 >= 17
2. 其他体质最高分 < 8

```json
{
  "conditions": [
    {
      "fieldCode": "pingheScore",
      "operator": "EXPRESSION",
      "expression": "#data['q1'] + (6 - #data['q2']) + (6 - #data['q4']) + (6 - #data['q5']) + (6 - #data['q13'])",
      "fieldValue": ">=17"
    },
    {
      "fieldCode": "otherMaxScore",
      "aggregateFunction": "MAX",
      "aggregateFields": "[\"qixuScore\",\"yangxuScore\",\"yinxuScore\"]",
      "operator": "LT",
      "fieldValue": "8"
    }
  ],
  "actions": [{
    "actionType": "RETURN",
    "actionParams": "{\"constitution\":\"平和质\",\"isYes\":true}"
  }]
}
```

## 7. 性能指标

基于性能测试结果：

| 指标 | 性能 |
|------|------|
| 单次表达式计算 | < 0.01 ms |
| 复杂表达式计算 | < 0.05 ms |
| 聚合函数(100字段) | < 0.005 ms |
| 规则编译 | < 0.2 ms |
| 并发表达式计算 | > 60,000 ops/sec |
| 并发聚合计算 | > 170,000 ops/sec |

## 8. 注意事项

1. **空值处理**: 聚合计算自动跳过 null 值
2. **类型转换**: 所有数值自动转换为 double 进行计算
3. **表达式验证**: 使用 `validate()` 方法在保存前验证表达式语法
4. **字段命名**: 字段名建议使用字母数字下划线，避免特殊字符

```http
  "ruleName": "自理能力等级判定-重度依赖",
  "sceneCode": "SELF_CARE_ASSESSMENT",
  "priority": 100,
  "conditions": [{
    "fieldCode": "totalScore",
    "aggregateFunction": "SUM",
    "aggregateFields": ["q1","q2","q3","q4","q5"],
    "operator": "BETWEEN",
    "fieldValue": "0,3"
  }],
  "actions": [{
    "actionType": "RETURN",
    "actionParams": {"result": "重度依赖", "level": 4}
  }]
}
```
